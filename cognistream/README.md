# CogniStream — Review 2 prototype

An adaptive lecture player that combines **local facial tracking**, an **experimental expression rule**, and **transcript-based learning support**.

Project context: *Autonomous Cognitive Load Intervention Using Facial Micro-Expression Tracking and Generative AI in Adaptive E-Learning Environments.* The implementation tracks facial expression cues; it does not validate cognitive load or specialised micro-expression recognition.

Team: Mohammed Jawwad (2AB23CI019), Mohammed Kashimji (2AB23CI020), Umair Hafiz (2AB23CI030). Guide: Ms. Veena. CSE (AIML), Anjuman Institute of Technology and Management.

## Run on Windows

**Already running v0.1? Follow `UPGRADE_WINDOWS.txt`.** Merge the updated files into your existing installation, preserving `backend/.venv` and `backend/.env`. Restart Python and refresh Chrome with Ctrl+F5.

The included production build needs **Python 3.10+ only**. Node.js is needed when editing/rebuilding the React source. Use the manual commands in `START_HERE.txt` if Smart App Control blocks a batch file.

Open a terminal in the `backend` folder and run:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

For an existing installation, run only the last command. Open **http://127.0.0.1:8000** and keep the terminal open. Stop with Ctrl+C. Do not overwrite a configured `.env` with the example.

Select **Play lesson** for the original **3 minute 51 second narrated lecture** about neural networks. It includes 44 sentence captions, VTT and SRT files, a plain-text transcript, six clickable chapters, and prepared teaching notes. Captions can be switched off and playback speed changed. Transcript lines jump to their matching video positions.

Camera support is optional. Select **Enable camera**, allow permission, and face the camera with your relaxed expression for five seconds. With the lecture playing, hold the selected brow/squint cues above the threshold for three seconds. Adjust sensitivity and recalibrate when necessary. Use **Help me understand** at any time covered by the transcript. The help panel pauses the video, labels the answer source, includes prepared sample self-checks, and offers Resume lecture. There is a ten-second cooldown afterwards.

The new interface adds a quick tour, setup steps, a transcript-follow option, clearer camera states, help-request retry, session export, and responsive phone layouts. See `docs/UI_DESKTOP.png`, `UI_SUPPORT.png`, and `UI_MOBILE.png` for actual browser screenshots.

## Enable live Gemini — optional

The project initially works with **prepared explanations for the bundled sample**. They are labelled; they are not generated by an LLM.

1. Obtain an API key in [Google AI Studio](https://aistudio.google.com/). Your ChatGPT subscription does not supply a Gemini key. Account limits and charges depend on your Google account and model.
2. Run setup first, then open the `backend` folder.
3. If `.env` does not exist, copy `.env.example` to `.env`. Open `.env` with Notepad. Windows may hide file extensions: File Explorer → View → Show → File name extensions.
4. Add your key after `GEMINI_API_KEY=`. Keep it private. Do not add it to frontend code, a report, a screenshot, or a Git repository.
5. `GEMINI_MODEL=gemini-3.5-flash-lite` is the initial model setting. It is intended for short, latency-sensitive responses. If this model is unavailable for your account, use a supported model ID from your Google account.
6. Save the file. Stop and restart the backend terminal. Click the refresh icon on the Your learning support card.
7. The support card indicates that a key is **configured**; it does not prove a request succeeded. A successful generated answer is labelled **Live Gemini explanation**.

If the live request fails, the modal explicitly announces a fallback. Custom lectures receive a literal transcript excerpt, not unrelated sample notes. We have not guaranteed that LLM responses are error-free.

## Use your own lecture

1. Click the upload icon beside the lesson title, then **Choose video** and select a browser-compatible MP4. The file stays local in your browser.
2. Click **Choose transcript** and select a matching `.vtt` or `.srt` file.
3. A custom video clears the previous transcript to prevent mismatched context. Uploading any replacement transcript disables prepared sample explanations.
4. Play the lecture. The transcript follows playback. Learning support selects overlapping cues from the preceding 30 seconds.
5. Enable Gemini to get generated help for custom content. With no key, the app shows a clearly labelled transcript excerpt.

The prototype does not transcribe videos automatically or import arbitrary YouTube links. A cue that overlaps the current timestamp may include the full cue text, including words spoken slightly later within that cue.

## What is implemented

| Module | Implemented behaviour |
|---|---|
| Lecture interface | Responsive React UI; narration, native captions, chapters, playback speed, transcript seeking; local video selection |
| Vision | Locally loaded MediaPipe model; webcam consent; face contours and expression coefficients |
| Calibration | Approximately five seconds of continuous visible-face samples; missing face restarts calibration |
| Heuristic | Baseline subtraction, weighted brow/squint cues, exponential smoothing |
| Trigger | Three seconds of sustained observations; resets on face loss, pause, seeking, hidden tab, or large frame gaps |
| Support | Recent transcript selection; FastAPI request; optional Gemini; explicitly labelled offline sample notes |
| Resume | Student-controlled continuation; ten-second cooldown |
| Activity | Timestamped events stored in browser local storage; JSON export; clear history |
| Demonstration | Separate, labelled simulation button for showing the downstream pipeline |

This is a proposed Review 2 scope. The college determines whether it meets its 60% requirement; the UI does not claim a validated completion percentage.

| Browser local storage | Small session event history | Stores local demo history without a database service |

## Algorithm in plain words

MediaPipe returns expression coefficients such as `browDownLeft` and `eyeSquintRight`. We average neutral samples to establish an individual baseline. We use **only increases above that baseline**.

```
brow = average(left brow excess, right brow excess)
squint = average(left squint excess, right squint excess)
raw score = clamp(200 × (0.65 × brow + 0.35 × squint), 0, 100)
smoothed score = 0.7 × previous score + 0.3 × raw score
```

The weights and scaling are prototype design choices, not learned or scientifically validated parameters. The score is not a probability. It is not a FACS AU intensity measurement.

We attempt inference at most about ten times per second to limit work on the browser thread. Actual speed depends on hardware. Once calibrated, a score over the chosen threshold for three observed seconds triggers a pause. This uses elapsed time rather than assuming a fixed number of frames. Frame gaps longer than one second reset the sustained timer. MediaPipe detection is synchronous, so lower-powered devices may still stutter; moving inference into a worker is future work.

## Troubleshooting

| Symptom | Action |
|---|---|
| Python not found | Install Python 3.12, select **Add Python to PATH**, and reopen setup |
| npm not found / unsupported Node | Install Node.js 22.12+ or Node 24; reopen the terminal |
| Setup fails while downloading | Check internet connectivity; rerun setup; preserve the displayed error for troubleshooting |
| Backend unreachable | Keep the backend terminal open; check its error; click the support card refresh icon |
| Port already in use | Stop old project terminals before starting another copy |
| Camera denied | Browser address bar → Site settings → Camera → Allow; close another app using the camera |
| Model missing | Extract the complete ZIP; rerun setup to copy the local WASM/module files |
| Camera works but no face | Face the camera, improve lighting, avoid covering your eyes/brows |
| Pauses too easily | Recalibrate neutrally and increase the threshold |
| Never auto-pauses | Confirm video is playing, calibration finished, cooldown expired; watch the score and adjust threshold |
| Video has no sound | Check the native player volume, laptop audio output, and browser tab mute; the bundled sample includes an AAC narration track |
| No transcript at timestamp | Load matching VTT/SRT; make sure its timestamps cover the current video position |
| Gemini fallback appears | Check key, quota, supported model, and internet; restart backend after changing `.env` |

## Limits and next work

- No evaluation of true confusion, mental fatigue, learning outcomes, demographic robustness, or detection accuracy has been conducted.
- A frown can have many causes. Expressions alone cannot establish comprehension.
- This implementation uses pretrained expression tracking and a rule; it does not train a new emotion classifier.
- No automatic speech-to-text, user accounts, cloud persistence, multi-user deployment, full RAG index, or email integration is included.
- Restricting the prompt to a transcript does not eliminate hallucinations.
- Webcam processing stays local. Gemini mode sends selected transcript text to an external service. Do not describe the whole application as fully offline when Gemini is enabled.
- Browser session history is local and capped at 200 events. It is not a central research database.
- Literature references from the pasted Gemini chat were not validated by this build. Replace invented authors and unsupported findings before academic submission.

## Regenerate the lecture assets (optional development task)

The supplied MP4 is ready to use. `scripts/generate_demo.py` generates the original slides, synthetic English narration, sentence captions, and chapter teaching notes. It requires FFmpeg, Pillow, and edge-tts; narration generation needs internet. These are build-time tools, not runtime dependencies of the player. Rebuilding narration creates new chapter timings, which are read by both the player and the prepared-support backend.

```sh
python -m pip install Pillow edge-tts==7.2.8
python scripts/generate_demo.py
npm run build --prefix frontend
```

Do not rerun this before the review unless you intend to regenerate the media. The archive already includes all generated assets. The interface font is locally bundled Inter, so rendering does not depend on an external font service.
